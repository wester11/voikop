# Подключение роутера VOID

Этот репозиторий содержит установщик для проверенных роутеров на OpenWrt.
Подключение начинается в ORBIT или в закрытой панели поддержки: там будет
готовая команда именно для вашего роутера и отдельный одноразовый код. Не
нужно устанавливать `git`, `sudo` или искать дополнительные файлы.

## Как подключить роутер

1. Откройте ORBIT и получите команду подключения.
2. Вставьте её в терминал роутера под пользователем `root` и запустите.
3. Когда установщик попросит код, вставьте одноразовый код из ORBIT и нажмите
   Enter.

Команда из ORBIT уже содержит адрес установщика и контрольную сумму текущей
версии. Она скачивает файл, сверяет его SHA-256 и запускает только при
совпадении. Копируйте команду целиком и не меняйте её вручную.

Код действует пять минут и может быть использован только один раз. Он вводится
уже после запуска команды, поэтому не попадает в историю терминала. Не
передавайте код, ссылку подписки, пароль роутера или приватные ключи кому-либо
и не публикуйте их в issues, commits или pull requests.

## Что изменится, а что нет

Перед любыми изменениями установщик проверяет модель роутера, версию OpenWrt,
свободное место и защищённое HTTPS-соединение. Неподдерживаемый роутер не будет
настраиваться автоматически.

На первом этапе VOID не меняет Podkop, sing-box, VPN-подписку и вашу
пользовательскую конфигурацию. Для этого роутера создаются отдельные ключи
WireGuard и SSH, а канал поддержки работает через физический WAN и не зависит
от вашей VPN или маршрутов Podkop.

Пароль `root` остаётся под вашим контролем: задайте или смените его через LuCI
либо командой `passwd`. Доступ к LuCI и SSH из интернета закрыт. Поддержка может
подключаться только по индивидуальному ключу внутри отдельного защищённого
WireGuard-канала; пароль владельца для этого не используется.

## Безопасность и приватность

В репозитории нет действующих кодов, ссылок подписок, паролей, сертификатов,
WireGuard-ключей, приватных API или адресов внутренней инфраструктуры. Ключи
создаются отдельно для каждого роутера: доступ к одному устройству не даёт
доступа к другим и не открывает административные сервисы.

Удалённый канал работает, только когда у роутера есть питание, физическое
подключение к WAN и доступ к провайдеру. Если одно из них недоступно, канал
поддержки также недоступен.
