# VOID для роутера: всё под контролем

Если вас привели сюда ORBIT или поддержка VOID — это нормально. Этот репозиторий
нужен, чтобы безопасно подключить **проверенный** роутер на OpenWrt. Мы не
просим пароль от роутера, ссылку на VPN-подписку или личные ключи: для первого
подключения они не нужны.

## Что происходит при подключении

В ORBIT или в закрытой панели поддержки вы получите готовую команду и отдельный
одноразовый код. Вставьте команду в терминал роутера под пользователем `root`,
а код — только когда установщик попросит его.

Команда уже содержит адрес нужной версии и её контрольную сумму. Перед запуском
установщик сверяет SHA-256 загруженного файла: если файл отличается от ожидаемой
версии, он не запускается. Код действует пять минут, работает один раз и
вводится отдельно, поэтому не остаётся в истории команд.

## Что остаётся вашим

- Пароль `root` знаете и меняете только вы — через LuCI или `passwd`.
- Ваша VPN-подписка, Podkop, sing-box и пользовательская конфигурация не
  заменяются на первом этапе.
- Доступ к LuCI и SSH из интернета закрыт. Поддержка не использует пароль
  владельца и не получает его.

Для каждого роутера создаются собственные ключи. Служебное подключение идёт по
зашифрованному WireGuard-каналу, а SSH внутри него принимает только
индивидуальный ключ. Ключ одного роутера не даёт доступа к другому.

## Что мы можем и чего не можем

VOID проверяет модель, версию OpenWrt, свободное место и HTTPS до изменения
настроек. Неподдерживаемое устройство не будет настраиваться автоматически.
Канал поддержки работает только пока у роутера есть питание, подключение к WAN
и доступ к провайдеру — скрытого доступа «на всякий случай» нет.

Шифруется служебный канал управления. Маршрутизация пользовательского трафика
зависит от выбранного вами профиля Podkop, Forkop или ZeroBlock: VOID не
превращает весь интернет-трафик в VPN без вашего выбора.

## Не публикуйте секреты

В репозитории нет действующих кодов, подписок, паролей, сертификатов,
WireGuard-ключей, приватных API или внутренних адресов. Не отправляйте код
подключения, ссылку подписки, пароль роутера или приватный ключ в чат, issue,
commit или pull request.
