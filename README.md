# VOID Router bootstrap

Публичный установщик для поддерживаемых роутеров на OpenWrt. Готовую команду
с одноразовым кодом выдаёт VOID Orbit или закрытая панель поддержки. На
OpenWrt команда запускается от `root`, поэтому `git` и `sudo` не требуются:

```sh
wget -qO- https://raw.githubusercontent.com/wester11/voikop/INSTALLER_COMMIT/install.sh | env VOID_ENROLLMENT_CODE='ONE_TIME_CODE' sh
```

Код действует пять минут и принимается только один раз. Не подставляйте в
команду ссылку подписки, пароль роутера или приватный ключ: они установщику не
нужны. Команда с кодом остаётся секретной до завершения активации.

## Что делает установщик

- проверяет модель, OpenWrt 24.10/25.x, свободное место и HTTPS;
- устанавливает проверенную по SHA-256 версию Podkop, если его ещё нет;
- получает конфигурацию только через `routersub.netvoid.ru`;
- отделяет ключи с метками YouTube/Ютуб/YT/ЮТ от остальных ключей;
- создаёт две управляемые секции Podkop: YouTube и зарубежный трафик;
- включает автоматическое обновление конфигурации;
- создаёт уникальные WireGuard- и SSH-ключи для каждого роутера;
- поднимает отдельный канал поддержки через физический WAN, не зависящий от
  Podkop, sing-box или пользовательской VPN;
- отключает парольный SSH только после проверки ключевого доступа с сервера.

Поддерживаются только модели и сборки, прошедшие отдельную проверку. На
неизвестном устройстве сервер завершит установку до изменения конфигурации.

## Безопасность

В репозитории нет реальных кодов, ссылок подписок, IP-адресов инфраструктуры,
паролей, сертификатов, WireGuard-ключей и приватных API. Не добавляйте их в
issues, commits или pull requests.

Один скомпрометированный роутер не даёт ключей другого роутера и не открывает
доступ к административным сервисам. Если физический WAN, питание или провайдер
недоступны, удалённый канал тоже работать не сможет.
