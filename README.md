# VOID Router bootstrap

Публичный репозиторий установщика для поддерживаемых роутеров на OpenWrt.

```sh
git clone https://github.com/wester11/voikop.git && cd voikop && sudo sh install.sh
```

Установщик попросит одноразовый код активации. Не вставляйте в команду ссылку
подписки, пароль роутера или приватный ключ: они не нужны и не должны попадать
в историю shell.

Код выдаётся в VOID Orbit или в закрытой панели поддержки, действует недолго,
хранится на сервере только в виде криптографического отпечатка и после первого
использования перестаёт работать.

## Что делает установщик

- проверяет, что запущен от `root` на OpenWrt 24.10 или новее;
- проверяет свободное место и WAN до внесения изменений;
- отправляет код только по HTTPS на `routersub.netvoid.ru`;
- получает конфигурацию только для одного роутера;
- создаёт резервную копию изменяемых конфигов и применяет изменения атомарно;
- настраивает Podkop и отдельный канал технической поддержки через физический
  WAN. Этот канал не использует Podkop, sing-box или пользовательскую VPN.

Поддерживаются только модели, прошедшие отдельную проверку. Скрипт прекращает
работу до изменения конфигурации на неизвестной модели или при ошибке
проверки подписи/HTTPS.

## Безопасность

В репозитории намеренно нет реальных IP-адресов, токенов, подписок, паролей,
сертификатов, ключей WireGuard и приватных API. Не добавляйте их в issues,
commits или pull requests.

Это bootstrap-код. Серверная выдача конфигурации включает одноразовый код,
per-device учётные данные и журналирование. Один скомпрометированный роутер не
должен давать доступ к другому роутеру или админским сервисам.
